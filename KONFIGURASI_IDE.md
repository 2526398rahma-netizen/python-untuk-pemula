# Konfigurasi Environment dan IDE

Catatan konfigurasi lingkungan kerja Python milik Rahma.

## Environment

- Sistem operasi: Windows 10
- Python: 3.13.17
- Virtual environment: folder venv (dibuat dengan python -m venv venv)
- Aktivasi: .\venv\Scripts\Activate.ps1

## IDE

- Konfigurasi editor disiapkan untuk Visual Studio Code lewat .vscode/settings.json
- Interpreter diarahkan ke venv\Scripts\python.exe
- Tab 4 spasi, format otomatis saat simpan
